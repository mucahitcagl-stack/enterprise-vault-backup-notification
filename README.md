# enterprise-vault-backup-notification
Kurumsal firmalarda yaygın olarak kullanılan Enterprise Vault uygulaması için geliştirdiğim bir otomasyonu paylaşmak istedim.

Hazırladığım script sayesinde, mail backup işlemleri sonrasında oluşan rapor dosyaları Task Scheduler üzerinden otomatik olarak çalıştırılıyor ve en güncel backup raporları alınarak özet bilgiler mail eki ile birlikte gönderiliyor. Ayrıca süreç sonunda, ekran görüntüsünde olduğu gibi bilgilendirme maili otomatik olarak oluşturuluyor.

Bu çalışma ile amaç; her gün sunucuya RDP bağlantısı yaparak manuel kontrol gerçekleştirmek yerine, gelen notification maili üzerinden hızlı bir şekilde ön kontrollerin yapılabilmesini sağlamak oldu. Böylece operasyonel kontrol süreci daha pratik ve hızlı hale geliyor.

Script’e aşağıdaki paylaşım linki üzerinden erişebilir, kendi kurumsal ortamınıza göre gerekli düzenlemeleri yaparak sorunsuz şekilde kullanabilirsiniz.

Umarım faydalı olur 🙂
