# enterprise-vault-backup-notification
Kurumsal ortamda enterprise vault ile alınan mail backuplarının windows task scheduler ile notification mail gönderilmesini sağlayarak kontrollerin sisteme login olmadan yapılmasını kolaylaştıran powershell scripttir.
Günlük olarak otomatik mail backup sonrası güncel dosya içerisindeki bilgileri alarak mail gönderiminin sağlamaktadır.
