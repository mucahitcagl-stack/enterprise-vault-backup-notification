# enterprise-vault-backup-notification
Kurumsal ortamda enterprise vault ile alınan mail backuplarının notification mail göndertmesini sağlayarak kontrolleri yapılması adına powershell scripttir.
Günlük olarak otomatik mail backup sonrası güncel dosya içerisindeki bilgileri alarak mail gönderiminin yapıldığı scripttir.
